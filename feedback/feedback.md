# User Feedback — daily-tech-digest

- **How collected:** Written comments via chat and GitHub Pages feedback — 3 people
- **When:** 2026-07-24

## Raw feedback

1. "The text alignment currently appears to be set to justify, which can create awkward spacing between words. Changing it to standard left-aligned text (`text-align: left`) would significantly improve readability."

2. "Clarified that viewing comments or discussions requires navigating directly to the original platform (Hacker News or Lobsters) via the provided 'Discuss' links."

3. "Individual news items feel visually crowded and clumped together. Adding more vertical margin/padding between cards and using clearer boundaries or subtle separators would make the layout much cleaner and easier to skim."

4. "The font style, hierarchy, and line height could be refined for better editorial balance and a modern, polished aesthetic."

5. "Updating the background, text, and accent colors (including dark/light mode adjustments) would enhance visual hierarchy and reduce eye strain."

## Themes (what keeps coming up)

- **Readability:** Multiple respondents mentioned text alignment, spacing, and typography — the page feels cramped and hard to skim.
- **Visual design:** Color palette and contrast came up as needing improvement for both dark and light modes.
- **UX clarity:** Users weren't sure where the "Discuss" links take them — needs clearer labeling.

## Top 3 things to fix

- [ ] Fix card spacing and layout structure (vertical padding, separators)
- [ ] Improve typography — font hierarchy, line height, alignment
- [ ] Refine color palette and contrast for dark/light modes
